UNMASKED: reference renders (round 20, 2026-10-17)

What the game looks like right now, for viewing without Unity or GitHub.

IMPORTANT: these are renders, not screenshots or recordings from Unity. The project's own software
renderer (Docs/tools/render3d.py) draws them from the same level, costume and case files Unity builds
the game from, so the layout, furniture, suspects and cases match. Unity's lighting, shaders,
HUD and animation will look different. Real in-game captures come once the project has been opened
in Unity: press F12 while playing and they are saved to Docs/screenshots/.
