# Fonts

Both typefaces are free under the SIL Open Font License 1.1 (OFL), so the game and the website can
ship them. The full licence texts are next to this file.

- **Fraunces** by Undercase Type (Phaedra Charles, Flavia Zimbardi). `Fraunces-Display.ttf` and
  `Fraunces-Title.ttf` are fixed instances of the variable font (soft, display and text optical
  sizes), made with fontTools so Unity's immediate-mode GUI can use them.
- **Atkinson Hyperlegible** by the Braille Institute of America, drawn for readers with low vision.

Source: github.com/google/fonts (ofl/fraunces, ofl/atkinsonhyperlegible).
